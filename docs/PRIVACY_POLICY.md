# 柠檬起始页隐私政策

> 最后更新：2026-08-31

本隐私政策适用于纯 Web 网页版 **柠檬起始页（Lemon New Tab）**（下称"本页面"）及其相关公开源代码仓库。

本页面以**本地优先**方式运行。部分联网功能为**默认启用或默认可用**，包括搜索建议和今日诗词；其他联网功能则通常需要您自行启用或配置，例如在线壁纸或部分第三方内容源。无论是否启用上述功能，本页面都不会主动向开发者服务器上传您的数据。当前版本代码中，开发者**不运营用于接收本页面用户个人数据的专用后端服务**。

联系邮箱：<lemon@redlnn.top>

## 1. 我们是谁

本页面的开发者为本项目仓库维护者。就本页面在本地设备上的功能而言，开发者尽量将数据处理限制在您的浏览器和设备内完成。

对于本页面功能的设计、提供和运行安排，在适用法律下，开发者在其实际决定处理目的和方式的范围内，作为**数据控制者/个人信息处理者**行事。

对于静态托管平台、第三方 API 或您自行填写的在线资源地址，其各自运营方可能作为**独立的数据处理者/控制者**处理相关数据；该等处理不由本页面开发者直接控制。

## 2. 本政策覆盖哪些数据处理活动

本政策覆盖以下三类场景：

1. **页面本地处理**：保存在您浏览器本地存储（localStorage、sessionStorage）或 IndexedDB 中的数据。
2. **第三方服务请求**：您启用联网功能时，您的浏览器直接向第三方服务发起的请求。
3. **托管与分发**：本页面由开发者或您自行部署的静态托管服务提供；托管平台在提供服务、记录日志或统计访问时可能自行处理的数据。

## 3. 本页面会处理哪些数据

### 3.1 本地存储的数据

本页面会在您的设备本地保存以下内容：

- 页面设置与界面偏好，例如主题、布局、搜索引擎配置、背景配置等；
- 快速导航链接、常用网站相关本地状态；
- 搜索历史（如果相应功能在本地启用）；
- 本地壁纸、视频壁纸、在线壁纸缓存及相关元数据；
- 云端同步码及上次同步时间（仅当您开启同步时）；
- 导入/导出设置产生的文件（由您自行保管）。

上述数据默认保存在您的浏览器环境中，由您或浏览器控制，不会自动发送给开发者。

### 3.2 联网时直接发给第三方的数据

当您使用默认启用或主动启用的联网功能时，您的浏览器会直接向第三方服务发送请求（详见第 6 节），这些请求由浏览器直接发出，不经过开发者服务器。

## 4. 我们不会做什么

除本政策另有说明外，本页面开发者**不会主动收集、出售、出租或上传**以下信息到开发者自有服务器：

- 您的身份信息、联系方式、支付信息；
- 您的浏览记录、搜索内容；
- 您本地图片、视频或文件内容；
- 页面设置、快速导航链接、壁纸文件或搜索历史。

## 5. 托管平台可能收集的数据

本页面为纯静态网页，可由开发者托管或由您自行部署。如果您通过第三方托管服务（例如 GitHub Pages、Vercel、Nginx 等）访问本页面，托管平台可能独立收集或处理以下信息：

- 访问 IP 地址、请求时间、User-Agent、来源页面；
- 访问日志、下载统计、诊断信息、使用分析。

这类处理不由本页面开发者直接控制。请您分别查阅相应托管平台及浏览器厂商的隐私政策：

- Google: <https://policies.google.com/privacy>
- Microsoft: <https://www.microsoft.com/privacy/privacystatement>
- Mozilla: <https://www.mozilla.org/privacy/>
- GitHub: <https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement>
- Vercel: <https://vercel.com/legal/privacy-policy>

## 6. 第三方服务与潜在风险

对于默认启用、默认可用或由您主动启用的联网功能，您的浏览器会直接与以下第三方服务通信。此时，第三方通常至少能够接收您的 **IP 地址、请求时间、User-Agent、请求参数、Referrer/来源上下文（取决于浏览器策略）** 等网络元数据，并可能按照其自身规则记录日志、风控、限流或进行跨境传输。

### 6.1 今日诗词 API

- 用途：获取古诗词内容；
- 代码中使用地址：`https://v2.jinrishici.com/one.json`
- 默认状态：**默认启用/默认可用**；
- 风险说明：今日诗词服务端可能接收并处理请求来源 IP 等网络信息。其接口返回内容中还可能包含与请求方相关的 token；开发者无法控制该服务的日志保留、地域路由和后续处理规则。

### 6.2 一言 API

- 用途：获取句子/语录内容；
- 代码中使用地址：`https://v1.hitokoto.cn`
- 风险说明：一言服务可能基于访问来源做限流、统计或安全防护，因此可能处理请求来源的网络元数据。相关处理由该服务独立决定。

### 6.3 搜索建议 API

- Google 搜索建议：`https://suggestqueries.google.com/`
- 百度搜索建议：`https://suggestion.baidu.com/`

用途：在您输入搜索词时返回联想建议。

风险说明：

- 相关搜索建议功能默认启用或默认可用；
- 您输入的搜索关键词会直接发送给对应搜索服务；
- 这些服务可能记录关键词、IP 地址、设备/浏览器信息和请求日志；
- 若您选择 Google 等境外服务，可能存在**跨境数据传输**。

### 6.4 在线壁纸源

- Lorem Picsum：`https://picsum.photos`
- Peapix：`https://peapix.com`（其图片直链来自 `img.peapix.com`）

用途：获取在线壁纸图片及元数据。

风险说明：

- 您的浏览器会直接向相应服务请求壁纸信息和图片；
- 该请求可能暴露您的 IP 地址、请求时间、设备/浏览器特征；
- 相关服务可能位于境外，涉及跨境数据传输，且其路由、缓存节点和实际处理地点可能因地区而异。

### 6.5 用户自定义在线壁纸/媒体 URL

- 用途：由您自行配置任意在线图片、视频或 API 地址；
- 风险说明：当您填写第三方在线地址后，您的浏览器会直接向相应站点发送请求。开发者无法审查或控制该站点的隐私实践、安全性、内容合法性、跨境传输、日志策略或后续用途。请仅使用您信任的资源提供方。

### 6.6 云端设置同步（可选）

- 用途：通过「同步码」在您的多台设备之间同步页面设置、快速导航与自定义搜索引擎；
- 数据存储：使用 `Cloudflare KV`，存储键为同步码的 SHA-256 哈希值，值为您的设置快照与同步时间戳；
- 默认状态：**默认关闭**，仅在您主动生成/输入同步码并执行上传或下载时启用；
- 风险说明：开启后，页面设置、快速导航与自定义搜索引擎内容会存储于 Cloudflare 的 KV（Cloudflare 为独立数据处理者，其边缘网络可能位于境外）。**同步码即访问凭证**——知道该同步码的人即可读取或覆盖您的云端设置，请妥善保管；本页面本地仅保存同步码本身。

## 8. 处理的法律依据（Lawful Basis）

在 GDPR 或类似制度适用时，开发者在其可实际控制的范围内主要基于以下法律依据处理数据：

### 8.1 履行服务所必需

对于本页面核心本地功能所必需的处理，例如保存设置、读取本地页面状态、渲染您已选择的页面布局与背景，本政策将其视为为提供您请求的页面功能所必需。

### 8.2 同意（Consent）

对于会使您的浏览器向第三方发送请求的联网功能，尤其是**默认启用或默认可用**的搜索建议和今日诗词，本页面将其视为基于您的**同意**运行。您可通过禁用相关功能、切换至不联网替代功能、阻止对应域名请求、清除相关缓存或停止访问本页面来撤回该同意。

对于您主动填写的在线壁纸、媒体 URL、第三方 API 地址或其他自定义联网资源，请求行为同样基于您的同意。

### 8.3 合法利益（Legitimate Interests）

在开发者或第三方服务提供方可适用的范围内，日志、速率限制、安全防护、故障排查、滥用检测、完整性维护和兼容性改进，可能基于合法利益进行处理。但该法律依据**不替代**默认第三方联网请求所需的同意基础。

### 8.4 法律义务

在适用法律要求披露、配合监管、响应合法请求或履行其他法定义务时，相关处理可能基于法律义务进行。

## 9. 数据保留策略

### 9.1 本地数据

本页面保存在您设备本地的数据通常会一直保留，直到发生以下任一情况：

- 您在页面设置、浏览器设置或开发者工具中手动清除；
- 您清除浏览器的站点数据或本地缓存；
- 浏览器自身因存储策略、清理机制或账户同步策略而删除相关数据。

### 9.2 第三方服务日志和缓存

对于今日诗词、一言、Google、百度以及您自定义的第三方资源，其日志、缓存、访问记录和保留期限由相应服务提供方决定。本页面开发者通常无法获知其确切保留时间，也无法代表其执行删除。

## 10. Cookie 与类似技术

本页面自身不会在开发者自有服务器上设置 Cookie，也不会在开发者控制的网页环境中使用追踪像素来识别您。

但在以下场景中，**第三方服务或托管平台**可能使用 Cookie、浏览器缓存、Local Storage、IndexedDB、ETag、日志标识符、设备标识符或其他类似技术：

- 搜索建议服务识别会话、路由地区、限流、防滥用；
- Google、百度或其他平台根据网络环境、区域或历史状态返回不同内容；
- 今日诗词或其他第三方接口返回或记录 token、缓存键或请求标识；
- 托管平台或浏览器厂商用于统计、访问日志和安全验证。

这些 Cookie 或类似技术由相应第三方独立控制，而非由本页面开发者直接控制。您通常可以通过浏览器设置、内容拦截规则、站点权限、无痕模式、退出登录或禁用相关功能进行管理。

## 11. 跨境数据传输

本页面开发者当前不运营专用后端来集中接收您的数据；但当您启用第三方联网功能时，您的请求可能被发送到中国大陆以外，或在中国大陆境内处理后再由第三方跨境传输。

因此，以下情形可能存在跨境数据传输风险：

- 使用 Google 搜索建议；
- 使用 Lorem Picsum、Peapix 等境外在线壁纸源；
- 使用您自行配置的境外在线壁纸、图片、视频或 API 地址；
- 使用云端设置同步（数据存储于 Cloudflare 全球边缘网络）。

不同司法辖区对个人信息保护程度可能不同。相关第三方服务可能采用的传输机制包括但不限于：标准合同条款（SCCs）、集团内部数据传输规则、法定认证/评估机制、数据本地化安排、区域节点调度，或基于您同意而发生的直接跨境请求。由于开发者并不控制这些第三方基础设施，开发者无法保证某一具体机制一定适用于所有服务或所有地区。

对于默认启用或默认可用的第三方请求功能，您可通过禁用相关功能、阻止相应域名请求、使用不联网替代功能或停止访问本页面，阻止后续跨境传输继续发生。
